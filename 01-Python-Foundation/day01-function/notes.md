# Day01 学习笔记：Python 函数

## 函数的基本结构

```python
def 函数名(形参):
    函数体
    return 返回值
```

- `def` 表示开始定义函数；
- 函数名应该表达它负责的动作；
- 形参是定义函数时声明的输入；
- 实参是调用函数时传入的具体数据；
- `return` 将结果交还给调用位置；
- 函数定义后不会自动运行，需要调用。

## 四类练习

| 类型 | Day01 示例 | 理解 |
|---|---|---|
| 无参函数 | 欢迎和健康码提示 | 封装固定动作 |
| 单形参函数 | 体温检测 | 相同逻辑处理不同输入 |
| 多形参函数 | 客户、业务类型、金额 | 一次业务由多个输入共同决定 |
| 返回值函数 | 年龄判断 | 让其他代码继续使用处理结果 |

## 对原始代码的复盘

1. Python 语句末尾不需要分号，统一去掉后更符合社区风格。
2. 原代码中 `query_balance()` 和 `continue_run()` 会互相继续调用，容易造成调用层级越来越深；整理版使用一个主菜单循环管理流程。
3. 存款函数调用 `query_balance()` 后不需要再次调用继续办理函数，否则会出现重复菜单。
4. `register()` 不需要 `while True`，注册一次后即可返回。
5. 金额需要验证为大于零，取款还需要验证余额是否充足。
6. `return True/False` 比返回 `True/None` 更清晰，调用者可以直接理解结果。
