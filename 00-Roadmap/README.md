# Transformation Roadmap

## Phase 1 — Python engineering foundation

Functions → containers → control flow → classes → files → exceptions → testing → APIs.

Current evidence:

- Day 01 completed: no-parameter functions, single/multiple parameters, return values and ATM integration practice.
- Day 02 queued: Python containers and customer-account data modeling.

**Exit criteria:** build and test a small business application without copying a tutorial.

## Phase 2 — AI application development

Model APIs, prompt design, structured output, tool calling, evaluation and cost awareness.

**Exit criteria:** deliver an assistant that solves one real implementation task.

## Phase 3 — RAG knowledge systems

Document ingestion, chunking, embeddings, retrieval, reranking, citations and evaluation.

**Exit criteria:** build a traceable enterprise knowledge assistant.

## Phase 4 — Agent systems

State, tools, planning, human approval, observability and failure recovery.

**Exit criteria:** automate a multi-step workflow with safe human checkpoints.

## Phase 5 — Enterprise AI delivery / FDE

Discovery, solution design, integration, security, deployment, adoption and ROI measurement.

**Exit criteria:** publish an end-to-end case study from customer problem to measurable result.
